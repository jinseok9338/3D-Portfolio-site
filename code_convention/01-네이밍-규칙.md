## 파일 네이밍

### 기본 규칙

| 분류 | 네이밍 규칙 | 예시 |
|------|-------------|------|
| 컴포넌트 | `PascalCase.tsx` | `UserProfile.tsx` |
| 훅 | `use*.ts` | `useAuth.ts` |
| 유틸리티 | `kebab-case.ts` | `date-utils.ts` |
| 타입 | `*.types.ts` | `user.types.ts` |
| 상수 | `*.constants.ts` | `api.constants.ts` |
| 테스트 | `*.test.ts(x)` | `UserProfile.test.tsx` |

### 컴포넌트 파일

```
# 단일 컴포넌트
Button.tsx

# 복합 컴포넌트 (디렉토리 구조)
UserCard/
├── index.ts          # 배럴 export
├── UserCard.tsx      # 메인 컴포넌트
├── UserCard.test.tsx # 테스트
└── UserCardSkeleton.tsx  # 관련 컴포넌트
```

### 페이지 파일 (React Router 7)

```
routes/
├── _index.tsx           # 홈 페이지 (/)
├── about.tsx            # /about
├── projects.tsx         # /projects
├── projects.$id.tsx     # /projects/:id (동적 라우트)
├── blog._index.tsx      # /blog
├── blog.$slug.tsx       # /blog/:slug
└── _auth.login.tsx      # /auth/login (레이아웃 그룹)
```

### 특수 파일 접미사

| 접미사 | 용도 | 예시 |
|--------|------|------|
| `.types.ts` | 타입 정의 | `user.types.ts` |
| `.constants.ts` | 상수 정의 | `routes.constants.ts` |
| `.utils.ts` | 유틸리티 함수 | `format.utils.ts` |
| `.hooks.ts` | 관련 훅 모음 | `form.hooks.ts` |
| `.schema.ts` | Zod 스키마 | `login.schema.ts` |
| `.queries.ts` | TanStack Query | `user.queries.ts` |
| `.store.ts` | Zustand 스토어 | `auth.store.ts` |

## 변수 네이밍

### 기본 규칙

```typescript
// camelCase 사용
const userName = 'John';
const isLoading = true;
const hasPermission = false;

// 배열은 복수형
const users = [];
const selectedItems = [];

// 객체는 단수형
```

### Boolean 변수

```typescript
// is/has/can/should 접두사
const isVisible = true;
const hasError = false;
const canSubmit = true;
const shouldRefetch = false;

// 부정형 피하기
// ❌ Bad
const isNotEmpty = true;
const hasNoError = false;

// ✅ Good
const isEmpty = false;
const hasError = false;
```

### 이벤트 핸들러 변수

```typescript
// on 접두사 (props로 전달되는 경우)
type Props = {
  onSubmit: () => void;
  onChange: (value: string) => void;
  onUserSelect: (user: User) => void;
};

// handle 접두사 (내부 핸들러)
const handleSubmit = () => {};
const handleInputChange = () => {};
```

### Ref 변수

```typescript
// Ref 접미사
const inputRef = useRef<HTMLInputElement>(null);
```

## 함수 네이밍

### 기본 규칙

```typescript
// 동사로 시작
function fetchUsers() {}
function calculateTotal() {}
function validateEmail() {}

// 명확한 동작 표현
function getUserById(id: string) {}      // 단일 조회
function getActiveUsers() {}             // 조건부 조회
function createUser(data: UserData) {}   // 생성
function updateUserProfile() {}          // 수정
function deleteComment(id: string) {}    // 삭제
```

### 동사 사용 가이드

| 동사 | 용도 | 예시 |
|------|------|------|
| `get` | 데이터 조회/반환 | `getUserName()` |
| `set` | 값 설정 | `setTheme()` |
| `fetch` | API 호출 | `fetchPosts()` |
| `create` | 새 객체/리소스 생성 | `createOrder()` |
| `update` | 기존 데이터 수정 | `updateProfile()` |
| `delete` | 삭제 | `deleteItem()` |
| `validate` | 유효성 검사 | `validateForm()` |
| `format` | 형식 변환 | `formatDate()` |
| `parse` | 파싱/분석 | `parseJSON()` |
| `convert` | 타입/형식 변환 | `convertToCSV()` |
| `check` | 조건 확인 (boolean) | `checkPermission()` |
| `is/has/can` | 상태 확인 (boolean) | `isValid()` |
| `toggle` | 상태 전환 | `toggleSidebar()` |
| `reset` | 초기화 | `resetForm()` |
| `init` | 초기 설정 | `initApp()` |

### 이벤트 핸들러 함수

```typescript
// 컴포넌트 내부: handle + 대상 + 동작
function handleButtonClick() {}
function handleFormSubmit() {}
function handleInputChange() {}

// Props로 전달: on + 대상 + 동작
type Props = {
  onButtonClick: () => void;
  onFormSubmit: (data: FormData) => void;
};
```

### Hook 함수

```typescript
// use 접두사 필수
function useAuth() {}
function useLocalStorage() {}
function useDebounce() {}

// 반환 타입이 명확하도록
function useToggle(): [boolean, () => void] {}
function useCounter(): { count: number; increment: () => void } {}
```

## 타입 네이밍

### 기본 규칙

```typescript
// PascalCase 사용
type User = { ... };
type ApiResponse = { ... };

// Interface는 I 접두사 사용하지 않음
// ❌ Bad
interface IUser { ... }

// ✅ Good
interface User { ... }
```

### Props 타입

```typescript
// 컴포넌트명 + Props
type ButtonProps = {
  variant: 'primary' | 'secondary';
  onClick: () => void;
};

type UserCardProps = {
  user: User;
  onSelect?: (user: User) => void;
};

// 또는 interface 사용
interface ModalProps {
  isOpen: boolean;
  onClose: () => void;
  children: React.ReactNode;
}
```

### 제네릭 타입

```typescript
// 의미있는 이름 사용 (단일 문자 지양)
type ApiResponse<TData> = {
  data: TData;
  error: string | null;
};

type ListProps<TItem> = {
  items: TItem[];
  renderItem: (item: TItem) => React.ReactNode;
};

// 관례적 약어 (허용)
// T: Type, K: Key, V: Value, E: Element
type Record<K extends string, V> = { [key in K]: V };
```

### Enum 및 Union

```typescript
// Enum: PascalCase (값도 PascalCase)
enum UserRole {
  Admin = 'Admin',
  Member = 'Member',
  Guest = 'Guest',
}

// Union Type: 선호 (Tree-shaking 가능)
type UserRole = 'admin' | 'member' | 'guest';
type ButtonVariant = 'primary' | 'secondary' | 'ghost';
type Size = 'sm' | 'md' | 'lg';
```

### API 관련 타입

```typescript
// 요청/응답 구분
type CreateUserRequest = { ... };
type CreateUserResponse = { ... };

// DTO 명시
type UserDTO = { ... };
type UserListDTO = { ... };

// 스키마 기반 타입 (Zod 사용 시)
import { z } from 'zod';

const userSchema = z.object({ ... });
type User = z.infer<typeof userSchema>;
```

## 체크리스트

### 파일 네이밍
- [ ] 컴포넌트는 PascalCase.tsx
- [ ] 훅은 use*.ts
- [ ] 유틸리티는 kebab-case.ts
- [ ] 테스트는 *.test.ts(x)

### 변수/함수
- [ ] 변수는 camelCase
- [ ] Boolean은 is/has/can/should 접두사
- [ ] 함수는 동사로 시작
- [ ] 이벤트 핸들러는 handle/on 접두사

### 타입
- [ ] 타입/인터페이스는 PascalCase
- [ ] Props 타입은 컴포넌트명 + Props
- [ ] I 접두사 사용하지 않음

### 상수
- [ ] 상수는 SCREAMING_SNAKE_CASE
- [ ] 객체 상수는 as const 사용
- [ ] 기능별로 그룹화

### CSS
- [ ] Tailwind 클래스는 논리적 그룹으로 정리
- [ ] CSS 변수는 --{category}-{name}-{variant}
